# brainfuck-optimized

`brainfuck-core` の素朴インタプリタと同じ意味論を保ったまま、連続命令の統合と代表的ループの一括適用によって
実行を速くする最適化インタプリタです。素朴実装を正解(オラクル)とする差分テストで観測的な一致を確認しています。

## 実行数の 2 つの定義

このクレートは実行数を 2 種類報告します。名称が示すとおり、両者は**別の定義**です。

| 名称 | フィールド | 定義 |
|------|-----------|------|
| 素朴換算の実行数 | `steps_executed` | 素朴実装(`brainfuck-core`)が同じ実行で数える実行数。統合・最適化された操作は、それが表す素朴実装の命令数だけ加算する。エラーで中断した場合も、素朴実装が同じ時点で数える値と一致する。 |
| IR 操作の実行回数 | `ir_ops_executed` | 最適化実装が一括適用した IR 操作の回数(方式固有の実行単位数)。縮退して素朴な 1 命令ずつの再生に回った命令は数えない。常に `ir_ops_executed <= steps_executed` が成り立つ。 |

ステップ制限(`MachineConfig` の上限)は素朴換算の実行数に対して適用されます。

## ベンチマーク

素朴実装と最適化実装の実行時間と実行数を、固定の 5 本のプログラムで比較するベンチマークを用意しています。
ベンチマーク用プログラムは `benches/programs/` にあり、それぞれ次の傾向を持ちます。

- `runs.bf`: 連続する `+` `-` `<` `>` が多いプログラム
- `clear.bf`: クリアループ `[-]` が多いプログラム
- `multiply.bf`: 移動/加算/乗算ループが多いプログラム
- `scan.bf`: 走査ループが多いプログラム
- `general.bf`: 一括適用されにくい一般ループが多いプログラム

### 実行コマンド

クレートのルート(ワークスペースのルートでもかまいません)で次を実行します。

```sh
cargo bench -p brainfuck-optimized
```

- ベンチマークは `cargo bench` で `bench` プロファイル(最適化ビルド)として実行されます。
- 入力は与えず、実行は外部プロセスを使わずに完結します。

### 通常のテストでは走らない

ベンチマークは標準のテストハーネスを使わない(`harness = false`)ターゲットです。
そのため `cargo test --workspace` では実行されません。正規テストは次で実行します。

```sh
cargo test --workspace
```

### 計測の手順

1. 各プログラムについて、素朴実装と最適化実装を実行し、観測結果(停止/エラー、`pc`、データポインタ、現在セル、
   素朴換算の実行数、停止フラグ、テープ全体、出力、入力読取位置)が一致し、素朴実装が停止することを確認します。
   1 本でも一致しない場合は計測せず、非ゼロ終了します。
2. 一致したプログラムについて、ウォームアップ 1 回の後に各 5 回計測し、中央値を採用します。
   計測対象は実行のみで、最適化実装の IR への変換は計測前に 1 回だけ行い、時間に含めません。

### 出力の読み方

出力の先頭に各列の定義が表示され、その後に次の形式の表が出力されます。

```
プログラム | 素朴換算の実行数 | IR操作の実行回数 | 素朴 ms | 最適化 ms |   倍率
```

- `素朴換算の実行数`: 素朴実装の `steps_executed`。両実装で常に同じ値です。
- `IR操作の実行回数`: 最適化実装の `ir_ops_executed`。素朴換算の実行数とは別の定義です。
  この値が小さいほど、より多くの命令が一括適用されたことを示します。一般ループ主体のプログラムでは差が小さくなります。
- `素朴 ms` / `最適化 ms`: 中央値の実行時間(ミリ秒)。
- `倍率`: `素朴 ms ÷ 最適化 ms`。1 より大きいほど最適化実装が速いことを示します。

### 注意

- **ベンチマークは最適化の正しさの証明ではありません。** 正しさは正規テスト(`cargo test --workspace`)で確認します。
- 時間の大小は成否判定に使いません。実行環境(負荷、電源設定など)によって数値は変動します。
  数値を比較する場合は、同じ環境で複数回実行してください。
- 両実装の観測結果が一致しない場合、ベンチマークは計測結果を表示せず失敗します。
